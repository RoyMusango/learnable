# Learnable

Application personnelle pour travailler chaque jour le cours Advanced Machine Learning (UMONS) : fiches, révision espacée, exercices générés, tuteur IA et préparation du projet. Chaque notion se travaille en quatre paliers : comprendre, retenir, appliquer, approfondir.

Application web statique, sans build, sur le moteur d’AppLangues. Les clés API restent dans le navigateur de chaque utilisateur. Formules rendues avec KaTeX (licence MIT, `js/vendor/katex`).
